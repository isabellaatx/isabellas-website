About This Project

This started as a mock research project where I aimed to see if a model could predict what genre of music someone is listening to from brain wave activity alone, and if that accuracy differed between musicians and non-musicians. I decided to actually build the model and perform the experiment, using synthetic EEG data I generated using randomizer functions in NumPy following what real results would be based on neuroscience research. I built a simple feedforward neural network using Tensorflow + Keras, and achieved a 96.2% accuracy for the musician model and a 73.1% accuracy for the non-musician model, which was expected. After this, I created a research poster for this project and presented it in front of classmates and some CS faculty.

About This Project

The FitX Fitness Tracker was a project I worked on in a 5-person team for a software development class. We built a full stack application that allowed users to log their workouts and create sets, log nutrition, and track their progress while being able to add friends as well. I specifically worked on the nutrition feature and integrating an external API as well as working with PostgreSQL databases for the register feature.
